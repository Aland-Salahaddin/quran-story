# Quran Stories: A Cinematic Kurdish Storytelling Platform

Welcome to the **Quran Stories** repository. This is a premium, cinematic-themed web platform dedicated to delivering rich Kurdish Audio Podcasts that explore the profound historical context of the Holy Quran. 

Built with **Next.js** and **Tailwind CSS**, the application presents a highly immersive digital experience.

## 🌌 Cinematic Vision & Design

The platform employs a deeply aesthetic, glassmorphic dark theme designed to evoke a sense of history, spirituality, and wonder. From micro-interactions and smooth transitions to starry backgrounds and elegant typography, every design decision focuses on creating a "WOW" factor for the user. It is not just an application; it is an atmospheric journey through history.

### Key Features
- **Cinematic Dark Mode UI**: A fully custom design system using rich dark tones, glassmorphic elements, and elegant gold accents to present a premium feel.
- **Kurdish Audio Podcasts**: Beautifully organized episode interfaces with integrated, sticky audio players to provide seamless listening experiences.
- **Story & Historical Context**: In-depth articles and verses that follow the timeline of the Holy Quran's revelation.
- **Integrated Voice Recorder / Teleprompter**: Custom telemetry tools embedded within the platform for an advanced content-creation and presentation workflow.
- **Fully Responsive**: Carefully tuned for optimal viewing on any device.
- **RTL Optimized**: Native Right-To-Left support optimized specifically for the Kurdish language.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Icons**: Heroicons / Custom SVGs

## 🚀 Getting Started

To run the development server locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🔐 Security & Privacy
This repository strictly ignores sensitive environment variables (`.env`, `.env.local`, `.env.production`) and build artifacts to maintain security and keep the repository clean.
